How to use them

OrderDocument 01 first if Git is new to you — 02 assumes it. Document 03 is independent and can be read at any point.
Type, don't pasteEvery document has commands to run. Typing them is slow for the first twenty and then it isn't. Your hands need to learn this, not your eyes.
Tick as you goEach document tracks which sections you've completed while the tab is open, so you can see how far through you are.
Use the questionsAnswer each one before opening the reveal. Getting one wrong is information, not failure — go back to the section it came from.
Link to a sectionHover any section heading and click the # to get a link straight to it. Useful when asking someone a question.
Come back to themThese are reference material as much as reading material. The glossaries and command cards at the end are meant to be returned to.

There is nothing to submit

No form, no upload, nothing to send anywhere. These are preparation for your own benefit, and the only person who needs to be satisfied by them is you.

Each document ends with a short list of things you should be able to do without looking anything up. If any of them feels shaky, go back to the section it came from and run the commands again. Nobody is checking, so there's no reason to pretend otherwise to yourself.
