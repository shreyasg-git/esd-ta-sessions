How to use them

Order00 is optional: read it if the Java in your project feels unfamiliar. 01 to 04 follow the labs in the order you did them.
Keep your project openEvery core section starts from lines of your own lab code, labelled with the git tag and file. Open that file beside the page and read along.
Missed a step?Clone ESD_Session and run git switch --detach lab1-complete (or lab2-complete) to get the code exactly as the lab ended.
Try itThe Try-it boxes are small pokes at code you already have: send a request, read the SQL, break one line and read the error, then put it back. You are not redoing the lab.
Tick as you goEach document tracks which sections you've read while the tab is open, so you can see how far through you are.
Use the questionsAnswer each one before opening the reveal. Getting one wrong is information, not failure — go back to the section it came from.
